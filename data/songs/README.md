# Songs

ここに楽曲フォルダを作り、`.tja` と対応する音源（`.ogg` / `.wav` / `.mp3`）を入れてください。

```text
data/songs/
  README.md
  MySong/
    MySong.tja
    MySong.ogg
```

`index.json` がない場合は各サブフォルダ内の `.tja` ファイルを自動検出します。ファイルを配置した後はゲームを再起動してください（曲が0件の場合は選曲画面でJを押して再読み込みできます）。

楽曲・譜面ファイルはリポジトリにコミットせず、このフォルダにローカルで保存してください。
